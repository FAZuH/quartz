# Quartz v5 — FAZuH's Notes

## Overview

[Quartz](https://quartz.jzhao.xyz/) v5 site generator for a digital garden. Fork of upstream `jackyzha0/quartz` with custom plugins and GitHub theme. Content is in `content/` (symlinked Obsidian vault). Published via GitHub Pages on push to `v5-fazuh`.

## Commands

```bash
npm run check         # tsc --noEmit && prettier --check
npm run format        # prettier --write
npm test              # tsx --test (Node.js native test runner)
npx quartz build      # build to public/
npx quartz build --serve --concurrency 12  # dev server
npx quartz plugin install  # install community plugins from config
npm run install-plugins   # same, via tsx (may fail; prefer CLI)
```

## Architecture

- **Config**: `quartz.config.default.yaml` — YAML-based. Plugins are community packages (`github:quartz-community/*`), installed to `.quartz/plugins/`.
- **Barrel file**: `.quartz/plugins/index.ts` is auto-generated by `npx quartz plugin install` (via esbuild, handles SCSS). Required for build. Do NOT commit `.quartz/`.
- **Build pipeline**: CLI (`npx quartz build`) → esbuild bundles `build.ts` with `sassPlugin` → executes. `npm run prebuild` (which calls `install-plugins.ts` via `tsx`) crashes on SCSS imports — never use `npm run build`; always use `npx quartz build`.
- **Plugins**: Transformer/markdown plugins use `remark` (markdownPlugins) or `rehype` (htmlPlugins). Client-side scripts via `externalResources`.
- **Custom plugins**: `quartz/plugins/local/fazuh-tweaks` (transformer) and `quartz/plugins/local/custom-breadcrumbs` (component). Referenced in config as `./quartz/plugins/local/...`.

## Custom Features

- **Title aliasing**: `FazuhTweaks` transformer rewrites `frontmatter.title` from `aliases[0]` (or `alias` string). Strips `.md`. Runs globally — all community components see aliased titles natively.
- **Embed transcludes**: `FazuhTweaks` adds `.embed` class to `blockquote.transclude` elements via rehype visitor.
- **Ctrl+/ search**: `FazuhTweaks` injects client-side script that triggers search button on `Ctrl+/`.
- **Custom breadcrumbs**: `custom-breadcrumbs` local plugin. Traverses `parent` frontmatter links (supports `[[wikilink]]` syntax and plain slugs) instead of folder hierarchy. Referenced as `./quartz/plugins/local/custom-breadcrumbs` in config.
- **GitHub theme**: `quartz/styles/themes/` with full Obsidian-like CSS variables. Imported via `@use "./themes"` in `custom.scss`.

## Publishing Model

- `ExplicitPublish` is enabled. Only notes with `publish: true` in frontmatter become HTML pages.
- `RemoveDrafts` is disabled.
- Static assets (non-md files) are copied by the `Assets` emitter regardless of `publish` status. Only excluded via `ignorePatterns` in config.
- Use [Quartz Syncer](https://quartz.jzhao.xyz/quartz-syncer) for selective sync from Obsidian.

## Vault Structure

`content/` is the Obsidian vault (not a symlink in this checkout). Contains:
- `1 Fleeting/`, `2 Personal/`, `3 Reference/`, `4 Projects/`, `5 Guideline/`
- `assets/` for linked media
- Hidden dirs (`.obsidian`, `.opencode`, `.git`) are excluded via `ignorePatterns` or `.gitignore`
- External dirs like `**/files/College/` contain symlinked datasets; add `ignorePatterns` entries for unwanted external content

## CI / Deploy

`.github/workflows/deploy.yml`:
- Trigger: push to `v5-fazuh`
- Steps: checkout → cache `.quartz/plugins` (keyed on `quartz.lock.json`) → `npm ci` → `npx quartz plugin install` → `npx quartz build` → upload `public/` → deploy to GitHub Pages

## Toolchain

- **TypeScript**: strict mode, `noUnusedLocals`, `noUnusedParameters`, `jsxImportSource: "preact"`
- **Prettier**: semi=`false`, printWidth=`100`, trailingComma=`all`, tabWidth=`2`
- **SCSS**: built-in emitter `componentResources.ts` imports SCSS. Handled by esbuild's `sassPlugin` during `npx quartz build`. `tsx` cannot process SCSS imports.
- **Testing**: Node.js native test runner (`node:test` + `node:assert`). Tests co-located with source files as `*.test.ts`. Run focused: `npx tsx --test path/to/file.test.ts`.
- **NPM**: `engine-strict=true` in `.npmrc`; Node >=22. `@quartz-community/types` and `@quartz-community/utils` are pinned to specific commit hashes in `package.json` to work around npm `min-release-age` CI issues.

## Gotchas

- `npm run build` triggers `prebuild` → `install-plugins` → crashes on SCSS. Always use `npx quartz build` directly.
- `.quartz/plugins/index.ts` must exist before build. Generated by `npx quartz plugin install` (not `install-plugins`).
- SCSS imports (`*.scss`) are processed by esbuild during `npx quartz build`, but NOT by `tsx`. If adding a custom plugin with SCSS, inline as a CSS string or ensure it's only loaded during the build pipeline.
- `glob()` in `Assets` emitter uses `gitignore: true` — respects both `ignorePatterns` from config AND `.gitignore`. Hidden dirs without a `.gitignore` entry will leak into `public/`.
- `slugifyFilePath` strips extensions. A file and directory with the same slugified name will collide in the output. The `Assets` emitter has no built-in collision handling.
