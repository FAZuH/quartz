> [!warning] Known issues
> 1. autorestic wouldn't work well with Tailscale's MagicDNS
> 2. autorestic does not recognize host's self-signed CA
>
> Due to the 2 issues above, it is best to use `http://100.64.0.1:3900` as S3 endpoint

## Common
### Set up & install autorestic

**Assumptions**
1. Autorestic installed
	```bash
	apt-get update 
	apt-get install -y bzip2 
	wget -qO - https://raw.githubusercontent.com/cupcakearmy/autorestic/master/install.sh | bash
	```
2. Crontab installed
3. Valid Rclone config (if using Rclone backend)
4. Valid .autorestic.env
5. Valid .autorestic.yml
6. Locations exists

**Steps**
1. Initialize autorestic

	```bash
	cd /opt/faz-lab/config/$(hostname)
	autorestic check
	```

2. Do `crontab -e`, and paste the `crontab.conf` configuration

### Set up Nginx UI autobackup

1. Open Nginx UI
2. Open **🕓 Backup** page
3. Open **Auto Backup** page
4. Click **Add**
5. Set configs:
	- Name: `s3.fazuh`
	- Backup Type: `Nginx and Nginx UI Config`
	- Storage Type: `s3`
	- S3 Endpoint: `http://vps-manager.device.fazuh.com:3900`
	- S3 Region: `garage`
	- Storage Path: `nginx-ui/`
6. Test connection, and done.
