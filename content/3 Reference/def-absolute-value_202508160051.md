## Definition

The **absolute value** $a\in\mathbb R$, denoted by $|a|$, is defined by
$|a| := \begin{cases} -a, &a<0\\ 0, &a=0\\ a, &a>0 \end{cases}$

We see from the definition of absolute value that, $\forall a \in \mathbb R$,

- $|a| \geq 0$
- $|-a| = |a|$
- $|a| = 0 \iff a = 0$
