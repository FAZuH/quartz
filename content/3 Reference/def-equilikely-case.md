## Definition
Let
- $\mathcal C=\{ x_{1},\dots, x_{m} \}$ : Finite [[3 Reference/Def-sample-space\|Definition of Sample Space]]
- $p_{i}=1/m,\quad\forall i=1,\dots, m$

If
- $\#(A)$ : Number of elements in set $A$
- $P(A)=\sum_{x_{i}\in A}1/m=\frac{\#(A)}{m},\quad\forall A\subset\mathcal C$

Then we say $P$ is a probability on $\mathcal C$, which we refer to as the **equilikely case**
