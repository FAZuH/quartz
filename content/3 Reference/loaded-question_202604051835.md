## Definition

Let:
- $Q$ : A question
- $A$ : An unjustified assumption embedded in $Q$

Then an argument commits the **Loaded Question** fallacy if and only if:
$$
Q \text{ contains assumption } A \text{ without justification}
$$

> [!TIP] Interpretation
> The question is framed such that any answer implicitly accepts the unjustified assumption.
