## Basic set notations
| Notation                          | Meaning                                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------------ |
| $x\in A$                          | $x$ is **in** $A$;<br>$x$ is a **member** of $A$;<br>$x$ **belongs** to $A$                |
| $x\not\in A$                      | $x$ **not in** $A$;                                                                        |
| $A\subseteq B$;<br>$B\supseteq A$ | Every element of $A$ also belongs to $B$;<br>$A$ is a **subset** of $B$                    |
| $A\subset B$;<br>$B\supset A$     | $A$ contains some element of $B$, but not all of $B$;<br>$A$ is a **proper subset** of $B$ |

## 1.1.1 Definition: Set equality



## Definition

Let $A,B$ : [[3 Reference/def-set_202510022014\|Set]]

If $A,B$ contains the same elements

Then
- We say $A$ and $B$ are **equal**
- We write $A=B$


Thus, to prove that the sets $A$ and $B$ are equal, we must show that $A\subseteq B$ and $B\subseteq A$.

## 1.1.3 Definition: Set union, intersection, complement


## Definition

We say the [[3 Reference/def-set_202510022014\|set]] $A\cup B := \{ x: x \in A \text{ or } x\in B \}$ is the **union** of $A$ and $B$

Let $n\in \mathbb{N}$. $\{ A_{1},A_{2},\dots,A_{n},\dots \}$ : Infinite collection of sets. Their **union** is the set of elements that belong to *at least one* of the sets $A_{n}$ :
$$
\bigcup_{n=1}^\infty A_{n} := \{ x:x \subset A_{n} \}
$$


## Definition

We say the [[3 Reference/def-set_202510022014\|set]] $A\cap B:=\{ x:x\in A \text{ and } x\in B\}$ is the **intersection** of $A$ and $B$

Let $n\in \mathbb{N}$. $\{ A_{1},A_{2},\dots,A_{n},\dots \}$ : Infinite collection of sets. Their **union** is the set of elements that belong to *all* of these sets $A_{n}$ :
$ \bigcap_{n=1}^\infty A_{n} := \{ x:x \subset A_{n} \} $$




## Definition
If $ A - B:=\{ x:x \in A\text{ and } x \not \in B \} $$

Then we say [[3 Reference/def-set_202510022014\|set]] $A- B$ is the **complement of $B$ relative to $A$**

## Remark

It is also often denoted by $A\setminus B$.

Or simply:
- Union: All elements existing in $A$, but not existing in $B$
- Intersection: All elements existing in either $A$ or $B$
- Complement: All elements existing in both $A$ and $B$ at the same time
