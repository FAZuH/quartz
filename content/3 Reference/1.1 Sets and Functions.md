## Basic set notations
| Notation                          | Meaning                                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------------ |
| $x\in A$                          | $x$ is **in** $A$;<br>$x$ is a **member** of $A$;<br>$x$ **belongs** to $A$                |
| $x\not\in A$                      | $x$ **not in** $A$;                                                                        |
| $A\subseteq B$;<br>$B\supseteq A$ | Every element of $A$ also belongs to $B$;<br>$A$ is a **subset** of $B$                    |
| $A\subset B$;<br>$B\supset A$     | $A$ contains some element of $B$, but not all of $B$;<br>$A$ is a **proper subset** of $B$ |
