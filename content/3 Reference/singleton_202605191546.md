Basically store a single instance globally to be used across the app. The class provides a method to get this instance.

In Rust, implemented using `LazyLock` stored in a `static` variable.

the type of a `static` value needs to implement the [`Sync`](https://doc.rust-lang.org/std/marker/trait.Sync.html "trait std::marker::Sync") trait. A `LazyLock<T>` is sync, if `T` is `Send + Sync`. Thus, neither `Rc` nor `RefCell` works for mutability. In this case, use `Arc<U>`, where `U` is `Send + Sync` (like `Mutex` or `RwLock`)

Related std blanket impls: 
```
impl<T, F> Sync for LazyLock<T, F>
where
	T: Sync + Send
	F: Send

impl<T, A> Sync for Arc<T, A>
where
    T: Sync + Send + ?Sized,
    A: Allocator + Sync,
```
