## Definition

Let 
- $A$ : Matrix

If $n=\operatorname{dim}[R(A)]=\operatorname{dim}[C(B)]$ 

Then 
- We call $n$ the **rank** of $A$
- We denote $n=\operatorname{rank}(A)$
- We call $\operatorname{dim}[N(A)]$ the **nullity** of $A$

## Theorem

Let $A$ : Matrix

Then $\operatorname{dim[R(A)]} = \operatorname{dim[C(A)]}$
