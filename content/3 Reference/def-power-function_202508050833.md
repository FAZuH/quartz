Power function is a function that returns the [[def-power-of-a-test_202508050833|power of a test]]

## Definition

We define **[[def-power-of-a-test_202508050833|power]] function** of a [[def-test_202508050827|critical region]] to be
$\gamma_{C}(\theta)=P_{\theta}[(X_{1},\dots,X_{n})\in C];\quad\theta\in \omega_{1}$

Suppose $C_{1},C_{2}$ : Critical regions, both of [[def-size-of-critical-region_202507291323|size]] $\alpha$

Then $C_{1}$ is better than $C_{2}$ if $\gamma_{C_{1}}(\theta)\geq \gamma_{C_{2}}(\theta), \forall \theta\in \omega_{1}$
