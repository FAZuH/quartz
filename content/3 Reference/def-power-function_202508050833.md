Power function is a function that returns the [[def-power-of-a-test_202508050833|power of a test]]

## Definition

We define **[[def-power-of-a-test_202508050833|power]] function** of a [[def-test_202508050827|critical region]] to be
$$ \gamma\_{C}(\theta)=P\_{\theta}\[(X\_{1},\dots,X\_{n})\in C];\quad\theta\in \omega\_{1} $$

Suppose $C\_{1},C\_{2}$ : Critical regions, both of [[def-size-of-critical-region_202507291323|size]] $\alpha$

Then $C\_{1}$ is better than $C\_{2}$ if $\gamma\_{C\_{1}}(\theta)\geq \gamma\_{C\_{2}}(\theta), \forall \theta\in \omega\_{1}$
