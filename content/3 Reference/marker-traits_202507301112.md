> Something used by the compiler to<u> "add" guarantees/assumptions to help creating theoretically safe code</u>.

---

There are 5 stable (non-experimental) [marker traits](https://doc.rust-lang.org/std/marker/index.html) as of Rust 1.88.0 (2025-07-30):

| Marker Trait                                                                              | Description                                                                                                               |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| [Copy](https://doc.rust-lang.org/std/marker/trait.Copy.html "trait std::marker::Copy")    | Can be `Clone`d by using bitwise copy.<br>Use `#[derive(Copy)]` to generate an impl of `Copy`                             |
| [Send](https://doc.rust-lang.org/std/marker/trait.Send.html "trait std::marker::Send")    | can be transferred across thread boundaries.                                                                              |
| [Sized](https://doc.rust-lang.org/std/marker/trait.Sized.html "trait std::marker::Sized") | Constant size known at compile time.                                                                                      |
| [Sync](https://doc.rust-lang.org/std/marker/trait.Sync.html "trait std::marker::Sync")    | Safe to share references between threads.<br>(i.e., `&T` is `Send`)                                                       |
| [Unpin](https://doc.rust-lang.org/std/marker/trait.Unpin.html "trait std::marker::Unpin") | Don't require any [pinning](https://doc.rust-lang.org/std/pin/index.html) guarantees.<br>Can be moved after it was pinned |
