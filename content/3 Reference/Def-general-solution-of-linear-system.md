## Definition

Let $\mathbf{Ax}=\mathbf{b}$ : [[Def-linear-system|Linear system]] that has infinitely many solutions.

Then **general solution** of $\mathbf{Ax}=\mathbf{b}$ is set of parametric equations from which all solutions can be obtained.
