## Definition

Let:
- $A, B$ : Two presented options
- $C$ : Other possible alternatives that exist

Then an argument commits the **False Dichotomy** (False Dilemma) fallacy if and only if it asserts:
$$
\text{Only } A \text{ or } B \text{ exist} \implies \text{Must choose } A \text{ or } B
$$

> [!NOTE]
> This fallacy ignores that more alternatives ($C$) may be possible.
