## Definition

We say the set $A\cap B:=\{ x:x\in A \text{ and } x\in B\}$ is the **intersection** of $A$ and $B$

Let $n\in \mathbb{N}$. $\{ A_{1},A_{2},\dots,A_{n},\dots \}$ : Infinite collection of sets. Their **union** is the set of elements that belong to *all* of these sets $A_{n}$ :
$$ \bigcap_{n=1}^\infty A_{n} := \{ x:x \subset A_{n} \} $$
