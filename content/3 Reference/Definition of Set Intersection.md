## Definition

We say the [[def-set_202510022014|set]] $A\cap B:={ x:x\in A \text{ and } x\in B}$ is the **intersection** of $A$ and $B$

Let $n\in \mathbb{N}$. ${ A\_{1},A\_{2},\dots,A\_{n},\dots }$ : Infinite collection of sets. Their **union** is the set of elements that belong to _all_ of these sets $A\_{n}$ :
$$ \bigcap\_{n=1}^\infty A\_{n} := { x:x \subset A\_{n} } $$
