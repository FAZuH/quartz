## Definition

A [[def-set_202510022014|set]] of two or more vectors in a [[def-real-inner-product-space_202510061214|real inner product space]] is said to be **orthogonal**, if all pairs of distinct vectors in the set are [[def-orthogonal_202510011638|orthogonal]].

An orthogonal set in which each vector has [[def-norm_202510010836|norm]] 1 is said to be **orthonormal**.
