## Definition

Let:
- $P$ : A proposition that is false
- $Q$ : An alternative proposition

Then an argument commits the **Limited Choice** fallacy if and only if it asserts:
$$
P \text{ is false} \implies \text{Only } Q \text{ can be true}
$$

> [!NOTE]
> This fallacy ignores other possible alternatives beyond $Q$.
