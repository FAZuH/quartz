## Definition

Let

- $X$ : [[mathstat1.5#Example pmf of discrete random variable|Random variable]]
- $F(x)$ : [[mathstat1.5#Definition 1.5.2 Cumulative distribution function (cdf)|cdf]] of $X$

If $F(x)$ is continuous for all $x\in \mathbb{R}$

Then we say $X$ is a **continuous random variable**

## Properties

If $X$ is continuous, then $P(X=x)=0,\quad\forall x\in \mathbb{R}$.
