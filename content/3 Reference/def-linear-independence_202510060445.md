## Definition

Let
- $V$ : [[3 Reference/def-vector-space-axioms_202509240715\|Vector space]]
- $S=\{ \mathbf{v}_{1},\mathbf{v}_{2},\dots,\mathbf{v}_{3} \}$ : [[3 Reference/def-set_202510022014\|Set]] of two or more vectors in $V$

If no vectors in $S$ can be expressed as a [[3 Reference/def-linear-combination_202510020342\|linear combination]] of the others

Then we say $S$ is a **linearly independent** set

Otherwise, we say $S$ is **linearly dependent**
