## Definition

Let:
- $A$ : An observed pattern or event
- $B$ : Another observed pattern or event

Then an argument commits the **Hasty Generalization** if and only if it asserts:
$$
A \text{ correlated with } B \implies A \text{ caused } B
$$

> [!NOTE]
> This fallacy confuses correlation with causation without sufficient evidence.
