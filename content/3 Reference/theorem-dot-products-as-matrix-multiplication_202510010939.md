## Theorem

| Form                                               | [[def-dot-product_202510010845\|Dot Product]]                              |
| -------------------------------------------------- | -------------------------------------------------------------------------- |
| $\mathbf{u},\mathbf{v}$ col [[Def-matrix\|matrix]] | $\mathbf{u}\cdot \mathbf{v}=\mathbf{u}^T\mathbf{v}=\mathbf{v}^T\mathbf{u}$ |
| $\mathbf{u}$ row matrix<br>$\mathbf{v}$ col matrix | $\mathbf{u}\cdot \mathbf{v}=\mathbf{u}\mathbf{v}=\mathbf{v}^T\mathbf{u}$   |
| $\mathbf{u}$ col matrix<br>$\mathbf{v}$ row matrix | $\mathbf{u}\cdot \mathbf{v}=\mathbf{v}\mathbf{u}=\mathbf{u}^T\mathbf{v}^T$ |
| $\mathbf{u},\mathbf{v}$ row matrix                 | $\mathbf{u}\cdot \mathbf{v}=\mathbf{u}\mathbf{v}^T=\mathbf{v}\mathbf{u}^T$ |
