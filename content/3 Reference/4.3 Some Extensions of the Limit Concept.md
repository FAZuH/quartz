### Theorem

Let
- $A\subseteq\mathbb{R}$
- $f:A\to\mathbb{R}$
- $c\in\mathbb{R}$
- $a\in \mathbb{R}$
- $(a,\infty)\subseteq A$

Then
- $c$ cluster point of $A$ 
	- $f(x)\leq g(x)\quad\forall x\in A, x\neq c$
		- $\implies$ $f(x)\leq g(x)\quad\forall x\in A, x\neq c$
		- $\implies$ $\lim_{ x \to c }g=-\infty \implies \lim_{ x \to c }f=-\infty$
- $c\in\mathbb{R}$ cluster point of $A\cap(c,\infty)$
	- $\iff$ $\lim_{x\to c+}f=L$
	- $\iff$ $\forall (x_n), (x_n) \to c \ni x_n \in A, x_n > c \forall n \in \mathbb N \implies (f(x_n)) \to L$
- $c\in\mathbb R$ cluster point of both $A\cap(c,\infty)$ and $A\cap(-\infty,c)$
	- $\implies$ $\lim_{x\to c}f = L \iff \lim_{x\to c+}f = L = \lim_{x\to c-}f$
- Some equivalency: [4.3.11 Theorem](#4.3.11%20Theorem), [4.3.14 Theorem](#4.3.14%20Theorem)
- [4.3.15 Theorem](#4.3.15%20Theorem)

## 4.3.1 Definition: One-sided limits

> Let 
> - $A\in \mathbb{R}$ 
> - $f:A\to \mathbb{R}$
> 
> Then
> 1. > Let 
>    > - $c\in \mathbb{R}$ is a cluster point of $A\cap(c,\infty)=\{ x\in A:x>c \}$
>    >
>    > If 
>    > - $\forall\varepsilon>0,\exists \delta>0\ni\forall x\in A,0<x-c<\delta \implies |f(x)-L|<\varepsilon$
>    >
>    > Then 
>    > - We say that $L\in \mathbb{R}$ is a **right-hand limit of $f$ at $c$**
>    > - $$\lim_{ x \to c+ } f=L$$
> 
> 2. > Let 
>    > - $c\in \mathbb{R}$ is a cluster point of $A\cap(-\infty,c)=\{ x\in A:x<c \}$
>    >
>    > If 
>    > - $\forall\varepsilon>0,\exists \delta>0\ni\forall x\in A,0<c-x<\delta \implies |f(x)-L|<\varepsilon$
>    >
>    > Then 
>    > - We say that $L\in \mathbb{R}$ is a **left-hand limit of $f$ at $c$**
>    > - $$\lim_{ x \to c- } f=L$$

## 4.3.5 Definition: Infinite limits

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to \mathbb{R}$
> - $c\in \mathbb{R}$ cluster point of $A$
> 
> Then
> 1. > If
>    > - $\forall\textcolor{yellow}\alpha\in\mathbb R, \exists\delta>0 \ni \forall x\in A, 0<|x-c|<\delta \implies f(x)\textcolor{yellow}{>\alpha}$
>    > 
>    > Then
>    > - We say that **$f$ tends to $\infty$ as $x\to c$**
>    > - $$\lim_{x\to c}f = \infty$$
>
> 2. > If
>    > - $\forall\textcolor{yellow}\beta\in\mathbb R, \exists\delta>0 \ni \forall x\in A, 0<|x-c|<\delta \implies f(x)\textcolor{yellow}{<\beta}$
>    > 
>    > Then
>    > - We say that **$f$ tends to $\infty$ as $x\to c$**
>    > - $$\lim_{x\to c}f = \infty$$

## 4.3.8 Definition: One-sided infinite limits

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to \mathbb{R}$
> - $c\in \mathbb{R}$ cluster point of $A\cap(c,\infty)$
> 
> If
> - $\forall \alpha\in \mathbb{R},\exists \delta>0\ni\forall x\in A,0<x-c<\delta\implies f(x)>a$ \[respectively, $f(x)<\alpha$\]
> 
> Then
> - We say **$f$ tends to $\infty$** \[respectively, $-\infty$\] as $x\to c+$,
> - $$ \lim_{ x \to c+ } f=\infty\quad\left[\text{respectively, }\lim_{ x \to c+ } f=-\infty\right] $$

## 4.3.10 Definition: Limits at infinity

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to \mathbb{R}$
> - $a\in \mathbb{R}$
> - $(a,\infty)\subseteq A$
> 
> If
> - $\forall \varepsilon>0,\exists K>a\ni\forall x>K\implies|f(x)-L|<\varepsilon$
> 
> Then
> - We say that $L\in\mathbb{R}$ is **limit of $f$ as $x\to \infty$**
> - $$ \lim_{ x \to \infty } f=L $$

## 4.3.13 Definition: Infinite limits at infinity

> Let
> - $A\subseteq\mathbb{R}$
> - $f:A\to\mathbb{R}$
> - $a\in \mathbb{R}$
> - $(a,\infty)\subseteq A$
> 
> If
> - $\forall \alpha\in \mathbb{R},\exists K>a\ni\forall x>K\implies f(x)>\alpha$ respectively, $f(x)<\alpha$
> 
> Then
> - We say **$f$ tends to $\infty$ \[respectively, $-\infty$] as $x\to \infty$**
> - $$ \lim_{ x \to \infty } f=\infty\quad\left[\text{respectively, }\lim_{ x \to \infty } f=-\infty\right] $$

## 4.3.2 Theorem

> Let
> - $A\subseteq\mathbb{R}$
> - $f:A\to\mathbb{R}$
> - $c\in\mathbb{R}$ cluster point of $A\cap(c,\infty)$
> 
> Then the following statements are equivalent:
> - $\lim_{x\to c+}f=L$
> - $\forall (x_n), (x_n) \to c \ni x_n \in A, x_n > c \forall n \in \mathbb N \implies (f(x_n)) \to L$

## 4.3.3 Theorem

> Let
> - $A\subseteq\mathbb R$
> - $f:A\to\mathbb R$
> - $c\in\mathbb R$ cluster point of both $A\cap(c,\infty)$ and $A\cap(-\infty,c)$
> 
> Then
> $$\lim_{x\to c}f = L \iff \lim_{x\to c+}f = L = \lim_{x\to c-}f$$

## 4.3.7 Theorem

> Let
> - $A\subseteq \mathbb{R}$
> - $f,g:A\to \mathbb{R}$
> - $c\in \mathbb{R}$ cluster point of $A$
> 
> If
> - $f(x)\leq g(x)\quad\forall x\in A, x\neq c$
> 
> Then
> 1. $\lim_{ x \to c }f=\infty \implies \lim_{ x \to c }g=\infty$
> 2. $\lim_{ x \to c }g=-\infty \implies \lim_{ x \to c }f=-\infty$

## 4.3.11 Theorem

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to\mathbb R$
> - $a\in \mathbb{R}$
> - $(a,\infty)\subseteq A$
> 
> Then the following statements are equivalent:
> - $\lim_{ x \to \infty }f = L$
> - $\forall(x_{n})\in A\cap(a,\infty)\ni\lim(x_{n})=\infty\implies(f(x_{n}))\to L$

## 4.3.14 Theorem

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to\mathbb R$
> - $a\in \mathbb{R}$
> - $(a,\infty)\subseteq A$
> 
> Then the following statements are equivalent:
> - $\lim_{ x \to \infty }f=\infty$ \[respectively, $\lim_{ x \to \infty }f=-\infty$]
> - $\forall(x_{n}) \in(a,\infty)\ni \lim(x_{n})=\infty\implies \lim(f(x_{n}))=\infty$ \[respectively, $\lim(f(x_{n}))=-\infty$]

## 4.3.15 Theorem

> Let
> - $A\subseteq \mathbb{R}$
> - $f,g:A\to\mathbb R$
> - $a\in \mathbb{R}$
> - $(a,\infty)\subseteq A$
> 
> If
> - $g(x)>0\quad\forall x>a$
> - $\lim_{ x \to \infty } \frac{f(x)}{g(x)}=L\quad L\in \mathbb{R},L\neq0$
> 
> Then
> - $L>0\implies (\lim_{ x \to \infty }f=\infty\iff \lim_{ x \to \infty }g=\infty)$
> - $L<0\implies (\lim_{ x \to \infty }f=-\infty\iff \lim_{ x \to \infty }g=\infty)$
