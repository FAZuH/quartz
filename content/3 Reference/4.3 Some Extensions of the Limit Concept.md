### Theorem

Let
- $A\subseteq\mathbb{R}$
- $f:A\to\mathbb{R}$
- $c\in\mathbb{R}$
- $a\in \mathbb{R}$
- $(a,\infty)\subseteq A$

Then
- $c$ cluster point of $A$ 
	- $f(x)\leq g(x)\quad\forall x\in A, x\neq c$
		- $\implies$ $\lim_{ x \to c }f=\infty \implies \lim_{ x \to c }g=\infty$
		- $\implies$ $\lim_{ x \to c }g=-\infty \implies \lim_{ x \to c }f=-\infty$
- $c\in\mathbb R$ cluster point of both $A\cap(c,\infty)$ and $A\cap(-\infty,c)$
	- $\lim_{x\to c}f = L$
		- $\iff \lim_{x\to c+}f = L = \lim_{x\to c-}f$
- $c\in\mathbb{R}$ cluster point of $A\cap(c,\infty)$
	- $\lim_{x\to c+}f=L$
		- $\iff$ $\forall (x_n)\in A, (x_n) \to c ,x_n > c \forall n \in \mathbb N \implies (f(x_n)) \to L$
- $\lim_{ x \to \infty }f=L$
	- $\iff \forall(x_{n})\in A\cap(a,\infty)\ni (x_{n})\to\infty\implies(f(x_{n}))\to L$
- $\lim_{ x \to \infty }f=\infty$
	- $\iff \forall(x_{n})\in A\cap(a,\infty)\ni (x_{n})\to\infty\implies(f(x_{n}))\to \infty$
- [4.3.15 Theorem](#4.3.15%20Theorem%20Ratio%20test)

## 4.3.1 Definition: f tends to L, x->c+-

> Let 
> - $A\in \mathbb{R}$ 
> - $f:A\to \mathbb{R}$
> 
> Then
> 1. > Let 
>    > - $c\in \mathbb{R}$ is a cluster point of $A\cap(c,\infty)=\{ x\in A:x>c \}$
>    >
>    > If 
>    > - $\forall\varepsilon>0,\exists \delta>0\ni\forall x\in A,0<x-c<\delta \implies |f(x)-L|<\varepsilon$
>    >
>    > Then 
>    > - We say that $L\in \mathbb{R}$ is a **right-hand limit of $f$ at $c$**
>    > - $$\lim_{ x \to c+ } f=L$$
> 
> 2. > Let 
>    > - $c\in \mathbb{R}$ is a cluster point of $A\cap(-\infty,c)=\{ x\in A:x<c \}$
>    >
>    > If 
>    > - $\forall\varepsilon>0,\exists \delta>0\ni\forall x\in A,0<c-x<\delta \implies |f(x)-L|<\varepsilon$
>    >
>    > Then 
>    > - We say that $L\in \mathbb{R}$ is a **left-hand limit of $f$ at $c$**
>    > - $$\lim_{ x \to c- } f=L$$

> [!TIP] Resembles [definition of limit](4.1%20Limits%20of%20Function.md#4.1.4%20Definition%20Limit%20of%20a%20function), but $x-c$ and $c-x$ instead of $|x-c|$

## 4.3.5 Definition: f tends to inf, x->c

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to \mathbb{R}$
> - $c\in \mathbb{R}$ cluster point of $A$
> 
> Then
> 1. > If
>    > - $\forall\textcolor{yellow}\alpha\in\mathbb R, \exists\delta>0 \ni \forall x\in A, 0<|x-c|<\delta \implies f(x)\textcolor{yellow}{>\alpha}$
>    > 
>    > Then
>    > - We say that **$f$ tends to $\infty$ as $x\to c$**
>    > - $$\lim_{x\to c}f = \infty$$
>
> 2. > If
>    > - $\forall\textcolor{yellow}\beta\in\mathbb R, \exists\delta>0 \ni \forall x\in A, 0<|x-c|<\delta \implies f(x)\textcolor{yellow}{<\beta}$
>    > 
>    > Then
>    > - We say that **$f$ tends to $\infty$ as $x\to c$**
>    > - $$\lim_{x\to c}f = \infty$$

> [!TIP] Resembles [definition of limit](4.1%20Limits%20of%20Function.md#4.1.4%20Definition%20Limit%20of%20a%20function), but $f>\alpha$ and $f<\beta$ instead of $|f-L|<\varepsilon$


## 4.3.8 Definition: f tends to inf, x->c+

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to \mathbb{R}$
> - $c\in \mathbb{R}$ cluster point of $A\cap(c,\infty)$
> 
> If
> - $\forall \alpha\in \mathbb{R},\exists \delta>0\ni\forall x\in A,0<x-c<\delta\implies f(x)>a$ \[respectively, $f(x)<\alpha$\]
> 
> Then
> - We say **$f$ tends to $\infty$** \[respectively, $-\infty$\] as $x\to c+$,
> - $$ \lim_{ x \to c+ } f=\infty\quad\left[\text{respectively, }\lim_{ x \to c+ } f=-\infty\right] $$

> [!TIP] Resembles [definition of limit](4.1%20Limits%20of%20Function.md#4.1.4%20Definition%20Limit%20of%20a%20function), but combination of [4.3.1](#4.3.1%20Definition%20f%20tends%20to%20L,%20x->c+-) and [4.3.5](#4.3.5%20Definition%20f%20tends%20to%20inf,%20x->c)

## 4.3.10 Definition: f tends to L, x -> inf

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to \mathbb{R}$
> - $a\in \mathbb{R}$
> - $(a,\infty)\subseteq A$
> 
> If
> - $\forall \varepsilon>0,\exists K>a\ni\forall x>K\implies|f(x)-L|<\varepsilon$
> 
> Then
> - We say that $L\in\mathbb{R}$ is **limit of $f$ as $x\to \infty$**
> - $$ \lim_{ x \to \infty } f=L $$

> [!TIP] Resembles [limit of a sequence](3.1%20Sequences%20and%20Their%20Limits.md#3.1.3%20Definition%20Converging%20and%20diverging%20(limit)%20of%20a%20sequence).

> - $(a,\infty)\subseteq A$
>

## 4.3.2 Theorem

> Let
> - $A\subseteq\mathbb{R}$
> - $f:A\to\mathbb{R}$
> - $c\in\mathbb{R}$ cluster point of $A\cap(c,\infty)$
> 
> Then the following statements are equivalent:
> - $\lim_{x\to c+}f=L$
> - $\forall (x_n)\in A, (x_n) \to c ,x_n > c \forall n \in \mathbb N \implies (f(x_n)) \to L$

> [!TIP] 
> Resembles [4.1.8 Theorem: Sequential criterion](4.1%20Limits%20of%20Function.md#4.1.8%20Theorem%20Sequential%20criterion), but $x_{n}>c$, since $x_{n}$ "approaches" $c$ from the right.

## 4.3.3 Theorem

> Let
> - $A\subseteq\mathbb R$
> - $f:A\to\mathbb R$
> - $c\in\mathbb R$ cluster point of both $A\cap(c,\infty)$ and $A\cap(-\infty,c)$
> 
> Then
> $$\lim_{x\to c}f = L \iff \lim_{x\to c+}f = L = \lim_{x\to c-}f$$

> [!TIP] No shit bro this is literally [4.1.4 Definition: Limit of a function](4.1%20Limits%20of%20Function.md#4.1.4%20Definition%20Limit%20of%20a%20function)

## 4.3.7 Theorem: Squeeze theorem

> Let
> - $A\subseteq \mathbb{R}$
> - $f,g:A\to \mathbb{R}$
> - $c\in \mathbb{R}$ cluster point of $A$
> 
> If
> - $f(x)\leq g(x)\quad\forall x\in A, x\neq c$
> 
> Then
> 1. $\lim_{ x \to c }f=\infty \implies \lim_{ x \to c }g=\infty$
> 2. $\lim_{ x \to c }g=-\infty \implies \lim_{ x \to c }f=-\infty$

> [!TIP] Analogous to [4.2.7 Theorem: Squeeze theorem](4.2%20Limit%20Theorems.md#4.2.7%20Theorem%20Squeeze%20theorem) and [3.6.4 Theorem](3.6%20Properly%20Divergent%20Sequences.md#3.6.4%20Theorem)

## 4.3.11 Theorem: Sequential criterion for 4.3.10

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to\mathbb R$
> - $a\in \mathbb{R}$
> - $(a,\infty)\subseteq A$
> 
> Then the following statements are equivalent:
> - $\lim_{ x \to \infty }f = L$
> - $\forall(x_{n})\in A\cap(a,\infty)\ni (x_{n})\to\infty\implies(f(x_{n}))\to L$

> [!TIP] As the name suggests, resembles [4.1.8 Theorem: Sequential criterion](4.1%20Limits%20of%20Function.md#4.1.8%20Theorem%20Sequential%20criterion)

## 4.3.14 Theorem: Sequential criterion for 4.3.13

> Let
> - $A\subseteq \mathbb{R}$
> - $f:A\to\mathbb R$
> - $a\in \mathbb{R}$
> - $(a,\infty)\subseteq A$
> 
> Then the following statements are equivalent:
> - $\lim_{ x \to \infty }f=\infty$ \[respectively, $\lim_{ x \to \infty }f=-\infty$]
> - $\forall(x_{n}) \in(a,\infty)\ni \lim(x_{n})=\infty\implies \lim(f(x_{n}))=\infty$ \[respectively, $\lim(f(x_{n}))=-\infty$]

## 4.3.15 Theorem: Ratio test

> Let
> - $A\subseteq \mathbb{R}$
> - $f,g:A\to\mathbb R$
> - $a\in \mathbb{R}$
> - $(a,\infty)\subseteq A$
> 
> If
> - $g(x)>0\quad\forall x>a$
> - $\lim_{ x \to \infty } \frac{f(x)}{g(x)}=L\quad L\in \mathbb{R},L\neq0$
> 
> Then
> - $L>0\implies (\lim_{ x \to \infty }f=\infty\iff \lim_{ x \to \infty }g=\infty)$
> - $L<0\implies (\lim_{ x \to \infty }f=-\infty\iff \lim_{ x \to \infty }g=\infty)$

> [!TIP] Analogous to [3.6.5 Theorem: Ratio test](3.6%20Properly%20Divergent%20Sequences.md#3.6.5%20Theorem%20Ratio%20test)
