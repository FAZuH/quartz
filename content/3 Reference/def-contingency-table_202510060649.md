## Definition

A rectangular table having $I$ rows for categories of $X$ and $J$ columns for categories of $Y$ displays the $I\cdot J$ possible combinations of outcomes.

The cells of the table represent the $I\cdot J$ possible outcomes.

When the cells contain frequency counts of outcomes for a sample, the table is called a contingency table
