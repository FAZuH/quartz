## Definition

Let $(x\_n)$ be a [[def-sequence-of-real-numbers_202510030255|sequence of real numbers]]

Then

- $(x\_{n})$ is **increasing** if it satisfies $$x\_1 \leq x\_2 \leq \dots \leq x\_n \leq x\_{n+1} \leq \dots$$
- $(x\_{n})$ is **decreasing** if it satisfies $$x\_1 \geq x\_2 \geq \dots \geq x\_n \geq x\_{n+1} \geq \dots$$
- $(x\_{n})$ is **monotone** if it's either increasing or decreasing
