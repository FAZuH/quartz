## Summary

### Definition

 - [Properly divergent sequence](#3.6.1%20Definition%20Properly%20divergent%20sequence) (tends to)

### Theorem

- $X, Y$ sequence of real numbers

1. $X$ monotone $\rightarrow$ ($X$ properly divergent $\leftrightarrow$ $X$ unbounded)
2. $X$ unbounded increasing $\rightarrow$ $\lim(x_{n}) = + \infty$
3. $X$ unbounded decreasing $\rightarrow$ $\lim(x_{n}) = - \infty$
4. $X > Y$ $\rightarrow$
	- $\lim X = +\infty$ $\rightarrow$ $\lim Y = + \infty$
	- $\lim Y = -\infty$ $\rightarrow$ $\lim X = - \infty$
5. $X, Y$ positive, $\lim \frac{X}{Y} = L \in \mathbb P$
   $\rightarrow$ $\lim X = +\infty \leftrightarrow \lim Y = +\infty$

## 3.6.1 Definition: Properly divergent sequence

> Let $(x_{n})$ be a sequence of real numbers
> 
> 1. We say that $(x_{n})$ **tends to** $\pm \infty$ and write $\lim(x_{n}) = + \infty$,
>    if for every $\alpha \in \mathbb R$ there exists a natural number $K(\alpha)$
>    such that $x_{n} > \alpha$, $\forall n\geq K(\alpha)$.
> 
> 2. We say that $(x_{n})$ **tends to** $-\infty$ and write $\lim(x_{n}) = -\infty$,
>    if for every $\beta \in \mathbb R$ there exists a natural number $K(\beta)$
>    such that $x_{n} < \beta$, $\forall n \geq K(\beta)$
> 
> We say that $(x_{n})$ is **properly divergent**
> in case we have either $\lim(x_{n}) = + \infty$ or $\lim(x_{n}) = -\infty$

## 3.6.3 Theorem

> A *monotone* sequence of real numbers is **properly divergent**
> **if and only if it is unbounded**.
> 
> Furthermore,
> 1. If $(x_{n})$ *unbounded increasing* sequence, then $\lim(x_{n}) = + \infty$
> 2. If $(x_{n})$ *unbounded decreasing* sequence, then $\lim(x_{n}) = - \infty$

## 3.6.4 Theorem

> Let $(x_{n})$ and $(y_{n})$ be two sequences of real numbers
> and suppose that *$x_{n} \geq y_{n}, \forall n \in \mathbb N$*.
> 
> 1. If $\lim(x_{n}) = +\infty$, then $\lim(y_{n}) = + \infty$
> 2. If $\lim(y_{n}) = -\infty$, then $\lim(x_{n}) = - \infty$

> [!TIP] Concept
> If $\lim X = + \infty$, and $X > Y$, $\lim Y$ must be higher and therefore $Y$ must converge to $+\infty$ too.

## Lemma

> If $\lim(y_{n}) = \infty$ and $c > 0$
> then $\lim(cy_{n}) = \infty$

## 3.6.5 Theorem: Ratio test

> Let $(x_{n})$ and $(y_{x})$ be two sequences of *positive* real numbers
> and suppose that for some *$L\in\mathbb P$ we have $\lim(x_{n}/y_{n}) = L$*.
> 
> Then $\lim(x_{n}) = + \infty$ if and only if $\lim(y_{n}) = + \infty$

## Examples

### Prove lim(n) is infinity

Prove $\lim(n) = \infty$

**We need to prove that 
for all $\alpha\in \mathbb{R}$
there exists $K(\alpha) > \alpha$
such that $x_{n} > \alpha$,  $\forall n\geq K(\alpha )$**

Let *$a\in \mathbb{R}$*, $(x_{n})$ a sequence of real numbers.

According to [Archimedean Property](2.4%20Applications%20of%20the%20Supremum%20Property.md#2.4.3%20Theorem%20Archimedean%20property), there exists $K(\alpha)\in \mathbb{N}$ such that *$K(\alpha) > \alpha$*.

Consequently, for all $x_{n} = n\geq K(\alpha) > \alpha$, we have $x_{n} > \alpha$.

$\therefore$ By definition of properly divergent sequence, we have $\lim(n) = \infty$.

### Prove lim(n^2) is infinity

Prove $\lim(n^2) = \infty$

Let *$a\in \mathbb{R}$*, $(x_{n})$ a sequence of real numbers.

Consider all cases for $\alpha$:

- If $\alpha \leq 0$, then $x_n = n^2 > 0 > \alpha, \quad \forall n \in \mathbb N$.
- If $\alpha > 0$, then according to [Archimedean Property](2.4%20Applications%20of%20the%20Supremum%20Property.md#2.4.3%20Theorem%20Archimedean%20property), there exists $K(\alpha)\in \mathbb{N}$ such that *$K(\alpha) > \sqrt\alpha$*.
	Consequently, for all $x_{n} = n^2 \geq (K(\alpha))^2 > \alpha$, we have $x_{n} > \alpha$.

$\therefore$ By definition of properly divergent sequence, we have $\lim(n) = \infty$.
