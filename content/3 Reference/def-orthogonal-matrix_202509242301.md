## Definition

Let $A$ : [[3 Reference/Def-matrix\|Square matrix]]

If $A^{-1}=A^T$ or equivalently, if $AA^T=A^TA=I$

Then we say $A$ is **orthogonal**

## Alternative definition

Square matrix $A$ is **orthogonal** if $A^{-1}=A^T$, or equivalently if $AA^T=A^TA=I$
