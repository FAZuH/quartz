## Definition

Let $A$ be any [[3 Reference/def-set_202510022014\|set]]

Then the **complement** of set $A$, denoted by $A^C$ is the set of all elements in the [[3 Reference/def-universal-set_202510030215\|universal set]] that is not in $A$.
$$
A^C := \{ x \in U: x \not\in A \} = U - A
$$
