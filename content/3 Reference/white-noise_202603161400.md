## Definition

A **White Noise** is a [[3 Reference/stochastic-process_202603161400\|stochastic process]] $\{ e_{t} \}$ that is:
1. Consisting of uncorrelated [[3 Reference/Def-random-variable\|random variables]] 
2. Mean 0 
3. Constant variance $\sigma^{2}_{e}$

## Properties

| Property                       | Expression                                                       |
| ------------------------------ | ---------------------------------------------------------------- |
| Mean ($\mu_{t}$)               | $0$                                                              |
| Variance                       | $\sigma^{2}_{e}$                                                 |
| Autocovariance<br>$\gamma_{k}$ | $\begin{cases} \sigma_e^2 & ,k = 0 \\ 0 & ,k \neq 0 \end{cases}$ |
| Autocorrelation<br>$\rho_{k}$  | $\begin{cases} 1 & ,k = 0 \\ 0 & ,k \neq 0 \end{cases}$          |
| Stationarity                   | [[3 Reference/strictly-stationary_202603161400\|Strictly Stationary]]        |
