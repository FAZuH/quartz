## Definition

A **White Noise** is a [[stochastic-process_202603161400|stochastic process]] ${ e\_{t} }$ that is:

1. Consisting of uncorrelated [[Def-random-variable|random variables]]
2. Mean 0
3. Constant variance $\sigma^{2}\_{e}$

## Properties

| Property                       | Expression                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| Mean ($\mu\_{t}$)               | $0$                                                                                         |
| Variance                       | $\sigma^{2}_{e}$                                                                            |
| Autocovariance<br>$\gamma_{k}$ | $\begin{cases} \sigma\_e^2 & ,k = 0 \ 0 & ,k \neq 0 \end{cases}$                            |
| Autocorrelation<br>$\rho\_{k}$  | $\begin{cases} 1 & ,k = 0 \ 0 & ,k \neq 0 \end{cases}$                                     |
| Stationarity                   | [[strictly-stationary_202603161400\|strictly]] and [[weakly-stationary_202603161400\|weakly]] |
