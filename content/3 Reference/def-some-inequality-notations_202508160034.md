## Definition

Let $a,b \in \mathbb R$.
- If $a-b \in \mathbb P$, then we write $a > b$ or $b < a$
- If $a-b \in \mathbb P \cup \set 0$, then we write $a\geq b$ or $b \leq a$

Based on the [[3 Reference/def-order-properties-of-real-numbers_202508160028\|Tricothomy Property]], if both $a \leq b$ and $a \geq b$, then $a = b$.

For notational convenience, we can write $a < b$ and $b < c$ as $a < b < c$. Also applies to the "or equal to" notation.
