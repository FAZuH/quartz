## Example

Let $X$ : [[Def-random-variable|Random variable]] with $X\sim N(\theta,100)$

Let $n=25$, thus the [[Def-sample-space|sample space]] is
$$
\mathcal{D} = { (x\_{1},x\_{2},\dots,x\_{25}):-\infty\<x\_{i}<\infty, i=1,2,\dots 25 }
$$

Let the [[def-test_202508050827|critical region]] $C\in \mathcal{D}$ be
$$ C = { (x\_{1},x\_{2},\dots,x\_{25}):x\_{1}+x\_{2}+\dots+x\_{25}>(25)(75) } $$

Notice that $\sum\_{i=1}^{25} x\_{i}>(25)(75)\iff  \bar{x}>75$. Therefore,
$$ C = { (x\_{1},x\_{2},\dots,x\_{25}):\bar{x}>75 } $$

- We reject $H\_{0} : \theta\leq75$ and accept $H\_{1} : \theta>75$ if and only if the sample mean is $\bar{x}>75$
- If $\bar{x}<75$, we accept $H\_{0} : \theta\leq75$

Because $X\sim(\theta,100)$, then $\bar{X}\sim(\theta,4)$ and $\frac{\bar{X}-\theta}{2}\sim N(0,1)$. We can then obtain
$$
\begin{align}
\gamma\_{C}(\theta) & = \operatorname{Pr}(\bar{X}>75) \\
& = \operatorname{Pr}\left( \frac{\bar{X}-\theta}{2} > \frac{75-\theta}{2} \right) \\
& = 1 - \operatorname{Pr}\left( \frac{\bar{X}-\theta}{2} \leq \frac{75-\theta}{2}\right) \\
& = 1 - \Phi\left( \frac{75-\theta}{2} \right)\quad\quad \text{(Because } \frac{\bar{X}-\theta}{2}\sim N(\theta,1))
\end{align}
$$
where $\Phi(x)$ is a distribution function from [[Continuous Distributions#Normal distribution|Normal distribution]]
