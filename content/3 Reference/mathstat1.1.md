## Definition: Random experiment
## Definition
**Random experiment** is any repeatable procedure that results in one out of a well-defined set of possible outcomes.

## Definition: Sample space
## Definition
**Sample space** is the set of all possible outcomes from a given [[3 Reference/Def-random-experiment\|random experiment]]

It is usually denoted as $\mathcal{C}$ and specified using set notation.

## Definition: Events
## Definition
**Events** are [[3 Reference/Def-subset\|subsets]] of [[3 Reference/Def-sample-space\|sample space]] $\mathcal{C}$.

It is generally denoted by capitol Roman letters e.g., $A,B,C$.

If the experiment results in an element in an event $A$, we say the event $A$ has occurred.
