## Definition

A [[def-discrete-time-markov-chain_202603280806|Markov chain]] is **irreducible** if there is only one [[def-communicating-classes_202603280822|communicating class]] — all [[def-state-stochastic_202603280801|states]] are [[def-communication_202603280821|communicative]].

> [!TIP] Interpretation
> In an irreducible chain, any state can be reached from any other state.
