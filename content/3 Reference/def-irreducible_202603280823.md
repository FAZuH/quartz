## Definition

A [[3 Reference/def-discrete-time-markov-chain_202603280806\|Markov chain]] is **irreducible** if there is only one [[3 Reference/def-communicating-classes_202603280822\|communicating class]] — all [[3 Reference/def-state-stochastic_202603280801\|states]] are [[3 Reference/def-communication_202603280821\|communicative]].

> [!TIP] Interpretation
> In an irreducible chain, any state can be reached from any other state.
