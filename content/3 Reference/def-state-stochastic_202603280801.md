## Definition

Values of a [[3 Reference/def-stochastic-process_202603280800\|stochastic process]] $X(t)$ are referred to as **states** of the process.

> [!TIP] Interpretation
> A state is a possible value the random variable can take — it exists whether or not you've observed it.
