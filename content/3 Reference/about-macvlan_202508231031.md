Some applications, especially legacy applications or applications which monitor network traffic, expect to be directly connected to the physical network. In this type of situation, you can use the `macvlan` network driver to <u>assign a MAC address to each container's virtual network interface, making it appear to be a physical network interface directly connected to the physical network</u>.

In this case, you need to designate a <u>physical interface on your Docker host</u> to use for the Macvlan, as well as the <u>subnet and gateway of the network</u>.
