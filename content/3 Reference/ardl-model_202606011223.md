Autoregressive Distributed Lag model for variables with mixed orders of integration; developed by Pesaran and Shin as an alternative when standard ECM cannot be applied.

## Definition

The **Autoregressive Distributed Lag (ARDL)** model is used when variables in a system have **different orders of integration** (some $I(0)$, some $I(1)$) but are [[Cointegration|cointegrated]].

The standard [[Error Correction Model (ECM)]] requires all variables to be integrated of the **same order** (typically $I(1)$) and cointegrated. When variables have **mixed** orders of integration, ECM cannot be applied directly.

### Why ARDL?

- The [[ECM Engle-Granger]] only works when all variables are non-stationary at level but stationary at the **same** differencing order
- If some variables are $I(0)$ (stationary at level) and others are $I(1)$ (stationary after first differencing), ARDL provides a valid framework

### Model Form

An ARDL($p$, $q$) model for two variables:

$$
Y_t = \alpha + \sum_{i=1}^{p} \beta_i Y_{t-i} + \sum_{j=0}^{q} \gamma_j X_{t-j} + e_t
$$

where:

- $p$ = number of lags of the dependent variable (autoregressive part)
- $q$ = number of lags of the independent variable (distributed lag part)

### Modeling Steps

The same steps as ECM:

1. Test for [[augmented-dickey-fuller-test_202603300223|stationarity]] of all variables
2. Test for [[Cointegration]] (bound test approach by Pesaran-Shin-Smith)
3. Estimate ARDL parameters

> [!NOTE]
> ARDL was developed by **Pesaran and Shin** and further extended with the **bound test** approach for cointegration testing by Pesaran, Shin, and Smith (PSS).
