## Definition: Vectors

Let

- $\mathbf{w}$ and $\mathbf{v}_{1},\mathbf{v}_{2},\dots,\mathbf{v}\_{4}$ : Vectors in $R^n$
- $k\_{1},k\_{2},\dots,k\_{r}$ : [[Def-matrix|Scalars]]

If
$$
\mathbf{w} = k\_{1}\mathbf{v}_{1} + k_{2}\mathbf{v}_{2}+\dots,k_{r}\mathbf{v}\_{r}
$$

Then

- We say $\mathbf{w}$ is a **linear combination** of $\mathbf{v}_{1},\mathbf{v}_{2},\dots,\mathbf{v}\_{r}$
- We call $k\_{1},k\_{2},\dots,k\_{r}$ the **coefficients** of the linear combination

## Definition: Matrices

Let

- $B$ and $A\_{1},A\_{2},\dots,A\_{r}$ : [[Def-matrix|Matrices]] of the same size
- $c\_{1},c\_{2},\dots,c\_{r}$ : [[Def-matrix|Scalars]]

If
$$
B = c\_{1}A\_{1}+c\_{2}A\_{2}+\dots+c\_{r}A\_{r}
$$

Then

- We say $B$ is a **linear combination** of $A\_{1},A\_{2},\dots A\_{r}$
- We call $c\_{1},c\_{2},\dots,c\_{r}$ the **coefficients** of the linear combination
