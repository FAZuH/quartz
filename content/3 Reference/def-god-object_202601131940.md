## Definition

A "God struct" (or [God Object/Class](https://www.google.com/search?q=God+Object%2FClass&oq=what+is+a+god+struct&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTINCAEQABiDARixAxiABDITCAIQLhiDARjHARixAxjRAxiABDINCAMQABiDARixAxiABDINCAQQABiDARixAxiABDIHCAUQABiABDIKCAYQLhixAxiABDINCAcQABiDARixAxiABDIHCAgQABiABDIGCAkQLhhA0gEIMjA2OWowajSoAgCwAgE&sourceid=chrome&ie=UTF-8&mstk=AUtExfD2pNEUN4EINy3z1suLqj4FODnSJaOmYstr7rkKCEqwMbE3cKzl7nXRTTIRr12q2R7PGpRdA9eIR0vEKIMjLBv4AxjKFNp1126xQiTzGMwsuW1U3DEjaFBOYrTpupmLZVhes7mP_3Q2WD1BKCO0z7SUYKX_qK9BQ7mW_Gzn8fjYkW8&csui=3&ved=2ahUKEwjf2YilxIiSAxUR2DgGHeswIo0QgK4QegQIARAD)) is ==a programming anti-pattern== where a single data structure (struct/class) takes on too many responsibilities, becoming excessively large and central to the system, violating [separation of concerns](https://www.google.com/search?q=separation+of+concerns&oq=what+is+a+god+struct&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTINCAEQABiDARixAxiABDITCAIQLhiDARjHARixAxjRAxiABDINCAMQABiDARixAxiABDINCAQQABiDARixAxiABDIHCAUQABiABDIKCAYQLhixAxiABDINCAcQABiDARixAxiABDIHCAgQABiABDIGCAkQLhhA0gEIMjA2OWowajSoAgCwAgE&sourceid=chrome&ie=UTF-8&mstk=AUtExfD2pNEUN4EINy3z1suLqj4FODnSJaOmYstr7rkKCEqwMbE3cKzl7nXRTTIRr12q2R7PGpRdA9eIR0vEKIMjLBv4AxjKFNp1126xQiTzGMwsuW1U3DEjaFBOYrTpupmLZVhes7mP_3Q2WD1BKCO0z7SUYKX_qK9BQ7mW_Gzn8fjYkW8&csui=3&ved=2ahUKEwjf2YilxIiSAxUR2DgGHeswIo0QgK4QegQIARAF) and making code hard to understand, maintain, and test.
