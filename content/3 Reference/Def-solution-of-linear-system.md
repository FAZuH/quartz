## Definition

**Solution** of [[Def-linear-system|linear system]] is defined as sequence of $n$ numbers $s\_{1},\dots,s\_{n}$ for which the substitution $x\_{1}=s\_{1},\dots,s\_{n}=x\_{n}$ make each equation in the linear system a true statement.

## Remark

For example, the linear system
$$
\begin{align}
5x + y = 3 \\
2x - y = 4
\end{align}
$$
has the solution $x=1,y=-2$. These solutions may be written as $(1,-2)$. More generally, the a solution of a linear system in $n$ unknowns can be written as $$
(s\_{1},\dots,s\_{n}) $$, which is called an **[[def-ordered-n-tuple_202510020339|ordered n-tuple]]**.
