## Definition
**Solution** of [[3 Reference/Def-linear-system\|linear system]] is defined as sequence of $n$ numbers $s_{1},\dots,s_{n}$ for which the substitution $x_{1}=s_{1},\dots,s_{n}=x_{n}$ make each equation in the linear system a true statement.

## Remark
For example, the linear system
$$
\begin{align}
5x + y = 3 \\
2x - y = 4
\end{align}
$$
has the solution $x=1,y=-2$. These solutions may be written as $(1,-2)$. More generally, the a solution of a linear system in $n$ unknowns can be written as $$
(s_{1},\dots,s_{n}) $$, which is called an **ordered n-tuple**.
