## Definition

Let $\mathbf{A}$ : [[3 Reference/Def-matrix\|Matrix]] of size $m\times n$

Suppose $R(\mathbf{A})$ is a set whose elements are row vectors with dimension $n$

If all vectors in $R(\mathbf{A})$ can be expressed as a linear combination of $m$ row vectors in $\mathbf{A}$

Then $R(\mathbf{A})$ is **row space** of $\mathbf{A}$
