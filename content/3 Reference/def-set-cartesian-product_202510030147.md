## Definition

Let $A,B$ be nonempty [[def-set_202510022014|sets]]

Then the **Cartesian product** $A\times B$ of $A$ and $B$ is the set of all ordered pairs $(a,b)$ with $a\in A$ and $b\in B$. That is,
$$
A\times B := { (a,b) : a\in A,b\in B }
$$
