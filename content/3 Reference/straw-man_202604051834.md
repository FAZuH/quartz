## Definition

Let:
- $P$ : The original proposition
- $P'$ : A distorted or weakened version of $P$

Then an argument commits the **Straw Man** fallacy if and only if it asserts:
$$
\text{I have an argument concerning } P' \implies P \text{ is false}
$$

> [!TIP] Interpretation
> Instead of addressing the actual argument, a distorted version is attacked instead.
