## Definition

We say the set $A\cup B := \{ x: x \in A \text{ or } x\in B \}$ is the **union** of $A$ and $B$

Let $n\in \mathbb{N}$. $\{ A_{1},A_{2},\dots,A_{n},\dots \}$ : Infinite collection of sets. Their **union** is the set of elements that belong to *at least one* of the sets $A_{n}$ :
$$
\bigcup_{n=1}^\infty A_{n} := \{ x:x \subset A_{n} \}
$$
