## Definition

We say the [[def-set_202510022014|set]] $A\cup B := { x: x \in A \text{ or } x\in B }$ is the **union** of $A$ and $B$

Let $n\in \mathbb{N}$. ${ A\_{1},A\_{2},\dots,A\_{n},\dots }$ : Infinite collection of sets. Their **union** is the set of elements that belong to _at least one_ of the sets $A\_{n}$ :
$$
\bigcup\_{n=1}^\infty A\_{n} := { x:x \subset A\_{n} }
$$
