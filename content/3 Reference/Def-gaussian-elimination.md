## Definition
**Gaussian elimination** is the procedure of using elementary row operation to transform an augmented matrix to row echelon form.

This procedure consists of:
1. **Forward phase**: Zeros are introduced below the leading 1's
2. **Back-substitution**: Starting from the last equation, solve for variables by substituting known values into previous equations

## Remark
For large linear systems, this is generally a more efficient solution.
