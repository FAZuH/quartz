## Definition

Let $\mathbf{v}$ nonzero vector in $R^n$

If
$$
\mathbf{u}=\frac{1}{||\mathbf{v}||}\mathbf{v}
$$

Then we say $\mathbf{u}$ is the **unit vector**

> [!note]
> A unit vector is a vector with [[def-norm_202510010836|norm]] $1$.
