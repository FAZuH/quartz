## Definition

Let $S$ be a nonempty subset of $\mathbb R$ ($S\neq \emptyset, S\subseteq \mathbb R$)

1.  If $\exists u\in\mathbb{R}\ni s\leq u,\; \forall s\in S$, then we say $S$ is **bounded above**
2.  If $\exists u\in\mathbb{R}\ni s\geq u,\; \forall s\in S$, then we say $S$ is **bounded below**
3. $S$ is **bounded** if $S$ is bounded above and below
