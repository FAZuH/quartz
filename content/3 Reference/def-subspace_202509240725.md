## Definition

Let

- $V$ : [[def-vector-space-axioms_202509240715|Vector space]]
- $W\subset V$

If $W$ is a vector space under the addition and scalar multiplication defined on $V$

Then $W$ is a **subspace of $V$**

## Theorem

Let

- $V$ : [[def-vector-space-axioms_202509240715|Vector space]]
- $W\subset V$

Then $W$ is a subspace of $V$

If and only if

- $\mathbf{u},\mathbf{v}\in W\implies \mathbf{u}+\mathbf{v}\in W$
- $k\text{ scalar},\mathbf{u}\in W\implies k\mathbf{u}\in W$
