## Definition

A [[3 Reference/Def-matrix\|square matrix]] in which all the [[3 Reference/Def-matrix\|entries]] above the [[3 Reference/Def-matrix\|main diagonal]] are zero is called **lower triangular** matrix.

A square matrix in which all the entries below the main diagonal are zero is called **upper triangular** matrix.

A [[3 Reference/Def-matrix\|matrix]] that is either upper triangular or lower triangular is called **triangular** matrix.
