## Definition

A [[3 Reference/Def-matrix\|square matrix]] $A$ is said to be **symmetric** if and only if $A=A^{T}$

## Alternative definition

[[3 Reference/Def-matrix\|Square matrix]] $A$ is **symmetric** $\iff A=A^T$
