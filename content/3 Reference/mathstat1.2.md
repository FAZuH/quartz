## Definition: Countable set
## Definition: Set complement


If $ A\setminus B:=\{ x:x \in A\text{ and } x \not \in B \} $$

Then we say set $A\setminus B$ is the **complement of $B$ relative to $A$**
## Definition: Subset

## Definition 

Let $A,B$ : Set

If every element of $A$ also belongs to $B$

Then
- We say $A$ is a **subset** of $B$
- We write $A\subseteq B$ or $B\subseteq A$

## Definition: Set union

If  $ A\cup B := \{ x: x \in A \text{ or } x\in B \} $$
 
Then we say set $A\cup B$ is the **union** of $A$ and $B$
