## Definition

Let:
- $P$ : The original proposition under discussion
- $Q$ : A related but different proposition

Then an argument commits the **Diversion (Red Herring)** fallacy if and only if it asserts:
$$
P \text{ is related to } Q \text{ and I have an argument regarding } Q \implies P \text{ is true}
$$

> [!NOTE]
> This fallacy shifts attention away from the original issue to a different but related topic.
