### Key Patterns to Memorize

$$\int \frac{f'(t)}{f(t)}dt = \ln|f(t)| + C \quad \text{(appears in } H(t) \text{ calculations)}$$

$$\int \frac{1}{a-t}dt = -\ln|a-t| + C \quad \text{(for } h(t) = \frac{1}{a-t} \text{ type hazard)}$$

$$\int_0^\infty \frac{1}{1+t^2}dt = \frac{\pi}{2} \quad \text{(arctan integral for mean)}$$

$$\frac{d}{dt}\ln S(t) = \frac{S'(t)}{S(t)} = -h(t) \quad \text{(hazard from survival)}$$

$$\text{MLE for exponential: } \hat{\lambda} = \frac{r}{\sum t_i} \quad \text{(}r = \text{number of events)}$$
