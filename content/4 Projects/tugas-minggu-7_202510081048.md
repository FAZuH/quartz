## Jawab

#### 5.1.a

- Syarat unbiasedness: $E[\epsilon|X]=0$
- Syarat konsistensi: $E[x_{t}\epsilon_{t}]=0$ untuk setiap $t$

Perbedaan:
- Unbiasedness: Ekspektasi b sama dengan parameter sebenarnya untuk sampel kecil
- Konsistensi: Estimator b konvergen ke b saat ukuran sampel mendekati tak hingga.

#### 5.1.b

Kondisi konsistensi $E\{x_t \varepsilon_t\} = 0$ untuk setiap $t$ dapat ditulis sebagai kondisi moment:
- $E[z_t \varepsilon_t] = 0$, di mana $z_t$ adalah vektor instrument yang mencakup $x_t$ dan memenuhi korelasi nol dengan $\varepsilon_t$, tetapi berkorelasi dengan $x_t$.

Estimator metode moment (IV atau GMM) didapat dengan meminimalkan jumlah kuadrat deviasi moment:
1. Tentukan kondisi moment populasi: $E[z_t (y_t - x_t' \beta)] = 0$.
2. Ganti ekspektasi dengan rata-rata sampel: $\frac{1}{T} \sum_{t=1}^T z_t (y_t - x_t' \beta) = 0$.
3. Selesaikan untuk $\beta$ dengan metode least squares terbebani menggunakan $z_t$ sebagai instrument, menghasilkan estimator IV:
   $$
   \hat{\beta}_{IV} = \left( X' Z (Z' Z)^{-1} Z' X \right)^{-1} X' Z y,
	$$
   di mana $Z$ adalah matriks instrument.

- Estimator OLS ($\hat{\beta}_{OLS} = (X' X)^{-1} X' y$) mengasumsikan $E\{x_t \varepsilon_t\} = 0$ secara langsung, tetapi gagal jika asumsi ini melanggar (misalnya endogenitas).
- Estimator IV/GMM berbeda karena menggunakan instrument $z_t$ untuk mengatasi korelasi antara $x_t$ dan $\varepsilon_t$, sehingga konsisten meskipun OLS tidak.
- Dalam kasus tanpa endogenitas, jika $x_t = z_t$, IV menyamai OLS, tetapi secara umum IV lebih robust terhadap endogenitas.

#### 5.1.c

1. **Variabel Endogenitas (Simultaneitas)**:

Misalnya, dalam model permintaan dan penawaran, $x_{i3}$ adalah harga barang, yang dipengaruhi oleh kuantitas yang juga dipengaruhi oleh error $\varepsilon_i$ (misalnya, faktor eksternal seperti cuaca). Ini menyebabkan $\text{cov}(\varepsilon_i, x_{i3}) \neq 0$ karena harga dan error saling bergantung.

2. **Kesalahan Pengukuran**:

Jika $x_{i3}$ adalah pendapatan yang dilaporkan dengan kesalahan pengukuran $u_i$, sehingga $x_{i3} = w_{i3} + u_i$ (di mana $w_{i3}$ adalah pendapatan sejati), dan $\varepsilon_i = v_i - \beta_3 u_i$ (dengan $v_i$ error acak), maka $\text{cov}(\varepsilon_i, x_{i3}) \neq 0$ karena $u_i$ berkorelasi dengan $x_{i3}$.

#### 5.1.d

Tidak, jika $\text{cov}(\varepsilon_i, x_{i3}) \neq 0$, estimator OLS menjadi inkonsisten, dan penyesuaian standar error (misalnya White atau Newey-West) tidak dapat mengatasi bias ini. Inferensi yang tepat tidak mungkin karena parameter estimasi tidak konvergen ke nilai sejati seiring bertambahnya sampel.

#### 5.1.e

Instrumental variable $z_i$ memenuhi $E[z_i \varepsilon_i] = 0$ dan berkorelasi dengan $x_{i3}$. Kondisi moment baru menjadi $E[z_i (y_i - x_i' \beta)] = 0$. Estimator alternatif (IV) didapat dengan menyelesaikan:
$$
\hat{\beta}_{IV} = (Z' X)^{-1} Z' y,
$$
di mana $Z$ adalah matriks instrument. Ini menggantikan asumsi $E[x_i \varepsilon_i] = 0$ dengan $E[z_i \varepsilon_i] = 0$, menghasilkan estimator konsisten.

#### 5.1.f
Estimator IV menggunakan $z_i$ yang mungkin kurang berkorelasi dengan $y_i$ dibandingkan $x_{i3}$ dalam OLS, sehingga variabilitas yang dijelaskan berkurang, menurunkan $R^2$. Ini menunjukkan $R^2$ bukan ukuran yang tepat untuk kebaikan model saat endogenitas ada, karena $R^2$ lebih mencerminkan kecocokan statistik daripada kebenaran kausal.

#### 5.1.g
Jika $E\{x_{i2} \varepsilon_i\} = 0$, $x_{i2}$ harus juga berkorelasi dengan $x_{i3}$. Namun, jika $x_{i2}$ dan $x_{i3}$ berkorelasi tinggi (misalnya variabel eksplanatori lain), $x_{i2}$ tidak independen dari $x_{i3}$ dalam konteks error, sehingga tidak valid sebagai instrument. $x_{i2}^2$ bisa digunakan jika $E\{x_{i2}^2 \varepsilon_i\} = 0$ dan $x_{i2}^2$ berkorelasi dengan $x_{i3}$, tetapi ini tergantung pada struktur data dan harus diuji.

#### 5.3.a

Dari kondisi first order conditional: 
$$
E_{T}\left\{ \delta \left( \frac{C_{t+1}}{C_{t}} \right)^{-\gamma}(1+r_{t+1})  \right\}
$$

Dapat ditulis ulang sebagai:
$$E_t\left\{\delta\left(\frac{C_{t+1}}{C_t}\right)^{-\gamma}(1 + r_{t+1}) - 1\right\} = 0$$

Karena $z_t$ adalah bagian dari information set pada waktu $t$, berlaku:
$$E\left\{\left[\delta\left(\frac{C_{t+1}}{C_t}\right)^{-\gamma}(1 + r_{t+1}) - 1\right]z_t\right\} = 0$$

Ini adalah **kondisi momen unconditional**. Estimasi konsisten untuk δ dan γ diperoleh dengan:

1. Membuat sample moment: $\frac{1}{T}\sum_{t=1}^T\left[\delta\left(\frac{C_{t+1}}{C_t}\right)^{-\gamma}(1 + r_{t+1}) - 1\right]z_t$
2. Meminimalkan fungsi kuadratik dari sample moments ini (GMM).

#### 5.3.b

**Minimum**: 2 kondisi momen (karena ada 2 parameter: δ dan γ).

**Keuntungan lebih banyak momen**:

- Estimasi lebih efisien
- Dapat menguji validitas spesifikasi model (overidentifying restrictions test)

#### 5.3.c

Gunakan **optimal weighting matrix**: $W^{opt} = (E{ff'})^{-1}$, dimana $f$ adalah fungsi momen.

Dalam praktik: prosedur 2-step GMM:

1. Step 1: estimasi dengan weighting matrix suboptimal (misal identity matrix) → dapat $\hat{\theta}^{[1]}$
2. Step 2: estimasi optimal weighting matrix menggunakan $\hat{\theta}^{[1]}$, lalu re-estimasi

**Tidak berfungsi jika**: weighting matrix bergantung pada θ yang tidak diketahui dan tidak dapat diestimasi konsisten.

#### 5.3.d

**Definisi**: Situasi dimana jumlah kondisi momen (R) melebihi jumlah parameter (K), yaitu R > K.

**Baik atau buruk**: **Baik**, karena:

- Memberikan informasi lebih untuk estimasi yang lebih efisien
- Memungkinkan pengujian validitas spesifikasi model
- Moment conditions yang berlebih dapat diuji secara statistik

#### 5.3.e

**Cara pelaksanaan**: Test statistic Sargan: $$\xi = T \cdot g_T(\hat{\theta}_{GMM})' W^{opt}_T g_T(\hat{\theta}_{GMM})$$

dimana $g_T(\theta) = \frac{1}{T}\sum_{t=1}^T f(w_t, z_t, \theta)$

**Distribusi**: $\xi \sim \chi^2(R-K)$ dimana R-K = degrees of freedom

**Null hypothesis**: Semua R kondisi momen adalah valid (benar).

**Jika test menolak**: Spesifikasi model ditolak - artinya data tidak konsisten dengan validitas semua R kondisi momen secara bersama-sama. Namun, tidak dapat diidentifikasi momen mana yang salah.

install.packages("Ecdat")
library(Ecdat)
library(AER)
data(Schooling)
head(Schooling)

#########
# 5.2.a #
#########

# Reduced form regression for schooling (ed76) with mother's and father's education
reduced_model <- lm(ed76 ~ momed + daded + age76 + I(age76^2), data = Schooling)
summary(reduced_model)

#########
# 5.2.b #
#########

# IV regression for returns to schooling using mom's and dad's education as instruments
iv_model <- ivreg(lwage76 ~ ed76 + age76 + I(age76^2) | momed + daded + age76 + I(age76^2), data = Schooling)
summary(iv_model, diagnostics = TRUE)

#########
# 5.2.c #
#########

# Sargan test for overidentifying restrictions
sargan_test <- summary(iv_model, diagnostics = TRUE)$diagnostics["Sargan", "p-value"]
print(paste("Sargan test p-value:", sargan_test))

#########
# 5.2.d #
#########

# IV regression with additional instrument (nearc2)
iv_model_extended <- ivreg(lwage76 ~ ed76 + age76 + I(age76^2) | momed + daded + nearc2 + age76 + I(age76^2), data = Schooling)
summary(iv_model_extended, diagnostics = TRUE)

# Sargan test for two overidentifying restrictions
sargan_test_extended <- summary(iv_model_extended, diagnostics = TRUE)$diagnostics["Sargan", "p-value"]
print(paste("Extended Sargan test p-value:", sargan_test_extended))

#########
# 5.2.e #
#########

# OLS model for reference
ols_model <- lm(lwage76 ~ ed76 + age76 + I(age76^2), data = Schooling)
summary(ols_model)

# Extract and compare coefficients
ols_educ <- coef(ols_model)["ed76"]
iv_educ_b <- coef(iv_model)["ed76"]
iv_educ_d <- coef(iv_model_extended)["ed76"]
cat("OLS ed76 coefficient:", ols_educ, "\n")
cat("IV ed76 coefficient (b):", iv_educ_b, "\n")
cat("IV ed76 coefficient (d):", iv_educ_d, "\n")
