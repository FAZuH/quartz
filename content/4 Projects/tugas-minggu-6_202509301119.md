## Soal
### Soal 1

- Estimasikan model OLS sederhana: wage ~ educ. Apa kelemahan  dari hasil ini?
- Lakukan estimasi IV regression dengan nearcollege sebagai instrumen untuk educ menggunakan paket AER. 

### Soal 2

- Estimasikan model di atas dan bandingkan hasilnya dengan model IV  sebelumnya.
- Lakukan uji overidentifikasi Hansen’s J test untuk menguji validitas instrumen. 
- Apa interpretasi hasil uji tersebut?

## Jawab

### Soal 1

#### 1a

![[assets/image-27.png]]

Diperoleh koefisien $\text{educ} = 3852.0$. Artinya, setiap tahun tambahan pendidikan meningkatkan wage sebesar $\$3,852$.

**Kelemahan:**

1. **Bias ke atas (overestimate)**: Koefisien OLS ($3852$) lebih tinggi dari nilai sebenarnya dalam simulasi ($3000$).
    
2. **Endogeneity**: Variable $\text{educ}$ berkorelasi dengan error term karena $\text{ability}$ (tidak teramati) mempengaruhi educ dan wage. Dalam konstruksi data:
    
	- $\text{educ}=12+2\times \text{nearcollege}+0.5\times \text{ability}+\epsilon$
    - $\text{wage}= 20000 + 3000\times\text{educ} + 5000\times \text{ability} + \epsilon$
    
    Ability masuk ke error term, sehingga $\operatorname{Cov}(\text{educ},u)\neq 0$.
    
3. **Estimasi tidak konsisten**: OLS melanggar asumsi exogeneity. Koefisien tidak menunjukkan efek murni dari pendidikan, melainkan mencampur efek ability.
    

#### 1b

![[assets/image-28.png]]

Diperoleh koefisien $\text{educ} = 3167.8$ - lebih rendah dari OLS, lebih dekat ke $3000$.

**Diagnostics:**

1. **Weak instruments test**: 
	- Diperoleh $p < 2\times 10^{-16}$ $\implies$ instrumen kuat
    - $\therefore$ $\text{nearcollege}$ relevan untuk memprediksi $\text{educ}$.
2. **Wu-Hausman test**: 
    - Diperoleh $p = 0.00108$ $\implies$ Tolak $H_{0}$ (exogeneity)
    - $\therefore$ $\text{educ}$ memang endogen. Akibatnya, OLS bias, sehingga IV diperlukan.

### Soal 2: Jawaban

#### 2a

![[assets/image-29.png]]

Diperoleh:
- IV1: $3167.8$
- IV2: $3161.2$

Perbedaan dari IV1 dan IV2 kecil ($\approx6.5$). keduanya konsisten dan cukup dekat dengan nilai sebenarnya ($3000$). 

Penambahan instrumen $\text{college\_count}$ pada IV2 redundan. Model tidak meningkatkan presisi atau mengubah estimasi.

#### 2b

Pada output kode [[4 Projects/tugas-minggu-6_202509301119#2a]], diperoleh hasil uji: Sargan statistic: $0.629$ (**p-value**: $0.428$)

Sargan test gagal tolak $H_{0}$. artinya, tidak ada bukti bahwa instrumen berkorelasi dengan error term.

#### 2c

**Hipotesis:**

- $H_{0}$: Semua instrumen valid (eksogen, tidak berkorelasi dengan error)
- $H_{1}$: Minimal satu instrumen tidak valid

**Keputusan:**

- $p = 0.428 > 0.05$ $\implies$ Gagal tolak $H_{0}$

**Interpretasi:**

1. **Instrumen valid**: Tidak ada bukti statistik baiwa instrumen-instrumen ($nearcollege$ dan $\text{college\_count}$) melanggar asumsi eksogenitas.
    
2. **Konsistensi instrumen**: Kedua instrumen memberikan informasi yang konsisten tentang efek $\text{educ}$ terhadap $\text{wage}$.
    
3. **Catatan penting dari first-stage**:

	![[assets/image-31.png]]
    - $\text{nearcollege}$: koef = 2.07, t = 20.4, p < 2e-16 $\implies$ sangat signifikan, instrumen kuat
    - $\text{college\_count}$: koef = -0.016, t = -0.585, p = 0.559 $\implies$ Tidak signifikan, instrumen lemah
    
    Meskipun $\text{college\_count}$ tidak berpengaruh signifikan di first-stage, hal ini tidak otomatis membatalkan validitasnya untuk overidentification test. Namun ini menjelaskan mengapa estimasi IV2 mirip dengan IV1 - karena variasi tambahan dari $\text{college\_count}$ minimal.

## Kode

```R
# ===== SETUP =====

set.seed(123)
n <- 500
ability <- rnorm(n, mean = 0, sd = 1)
nearcollege <- rbinom(n, 1, 0.5)
educ <- 12 + 2*nearcollege + 0.5*ability + rnorm(n)
wage <- 20000 + 3000*educ + 5000*ability + rnorm(n, 0, 5000)
data <- data.frame(wage, educ, nearcollege, ability)

library(AER)
library(sandwich)
library(lmtest)
library(car)



# ===== SOAL 1 =====

# 1a
ols <- lm(wage ~ educ, data = data)
summary(ols)

# 1b
iv1 <- ivreg(wage ~ educ | nearcollege, data = data)
summary(iv1, diagnostics = TRUE)




# ===== SOAL 2 =====

# 2a
college_count <- rpois(n, lambda = 3)
data$college_count <- college_count

iv2 <- ivreg(wage ~ educ | nearcollege + college_count, data = data)
summary(iv2, diagnostics = TRUE)

# 2b
first_stage <- lm(educ ~ nearcollege + college_count, data = data)
summary(first_stage)
```
