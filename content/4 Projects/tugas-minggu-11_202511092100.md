# Model Persamaan Simultan

## 1. Simultaneous Model

### Masalah pada Model Persamaan Tunggal

Dalam regresi linear, hubungan sebab-akibat berjalan satu arah: dari variabel X ke variabel Y. Model ini mengasumsikan bahwa variabel X bersifat eksogen ($E\[\varepsilon\_i|\mathbf{x}\_i]=0$) dan tidak berkorelasi dengan error term.

Namun, dalam situasi ekonomi, seringkali ditemukan bahwa Y ditentukan oleh X, tetapi pada saat yang sama, beberapa variabel X juga ditentukan oleh Y. Dengan kata lain, terdapat hubungan dua arah atau **hubungan simultan** antara Y dan (beberapa) X.

### Konsep Model Persamaan Simultan

Model persamaan simultan adalah sistem yang terdiri dari M persamaan untuk M **variabel endogen**. Bentuk umum model dengan M persamaan:

$$
\begin{align}
Y\_{1t} & = \beta\_{12}Y\_{2t} + \beta\_{13}Y\_{3t} + \cdots + \beta\_{1M}Y\_{Mt} + \gamma\_{11}X\_{1t} + \gamma\_{12}X\_{2t} + \cdots + \gamma\_{1K}X\_{Kt} + u\_{1t} \\

Y\_{2t} & = \beta\_{21}Y\_{1t} + \beta\_{23}Y\_{3t} + \cdots + \beta\_{2M}Y\_{Mt} + \gamma\_{21}X\_{1t} + \gamma\_{22}X\_{2t} + \cdots + \gamma\_{2K}X\_{Kt} + u\_{2t} \\

\vdots \\

Y\_{Mt} & = \beta\_{M1}Y\_{1t} + \beta\_{M2}Y\_{2t} + \cdots + \beta\_{M,M-1}Y\_{M-1,t} + \gamma\_{M1}X\_{1t} + \gamma\_{M2}X\_{2t} + \cdots + \gamma\_{MK}X\_{Kt} + u\_{Mt}
\end{align}
$$

Karakteristik utama:

1. **Interdependensi**: Variabel endogen dalam satu persamaan muncul sebagai regressor dalam persamaan lain
2. **Simultaneity**: Variabel-variabel endogen ditentukan secara bersamaan dalam sistem
3. **Structural equations**: Setiap persamaan menggambarkan struktur atau perilaku ekonomi tertentu

### Mengapa OLS Tidak Tepat?

Salah satu asumsi OLS adalah variabel explanatory tidak berkorelasi dengan error term. Dalam model persamaan simultan, asumsi ini dilanggar karena:

1. Variabel endogen yang muncul sebagai regressor bersifat stokastik
2. Variabel endogen tersebut berkorelasi dengan error term: $\text{cov}(Y\_j, u\_i) \neq 0$

Konsekuensinya, estimator OLS **bias dan tidak konsisten**. Bias tidak hilang bahkan ketika ukuran sampel bertambah besar tanpa batas.

## 2. Contoh Simultaneous Model

### Contoh 1: Model Permintaan dan Penawaran

Harga P dan kuantitas Q ditentukan oleh perpotongan kurva permintaan dan penawaran:

**Fungsi permintaan:** $$Q\_t^d = \alpha\_0 + \alpha\_1 P\_t + u\_{1t}, \quad \alpha\_1 < 0$$

**Fungsi penawaran:** $$Q\_t^s = \beta\_0 + \beta\_1 P\_t + u\_{2t}, \quad \beta\_1 > 0$$

**Kondisi equilibrium:** $$Q\_t^d = Q\_t^s$$

P dan Q adalah variabel endogen yang ditentukan secara simultan. Ketika $u\_{1t}$ berubah (perubahan pendapatan, wealth, selera), kurva permintaan bergeser dan mengubah P dan Q. Demikian pula, perubahan $u\_{2t}$ (cuaca, strikes, pembatasan impor) menggeser kurva penawaran. Karena interdependensi ini, $P\_t$ berkorelasi dengan $u\_{1t}$ dan $u\_{2t}$.

### Contoh 2: Model Keynesian Penentuan Pendapatan

**Fungsi konsumsi:** $$C\_t = \beta\_0 + \beta\_1 Y\_t + u\_t, \quad 0 < \beta\_1 < 1$$

**Identitas pendapatan:** $$Y\_t = C\_t + I\_t$$

Di mana C = konsumsi, Y = pendapatan, I = investasi (eksogen), dan $\beta\_1$ = marginal propensity to consume (MPC).

C dan Y adalah variabel endogen yang saling mempengaruhi. Ketika $u\_t$ berubah, fungsi konsumsi bergeser dan mempengaruhi Y. Oleh karena itu, $Y\_t$ berkorelasi dengan $u\_t$, sehingga OLS tidak tepat.

## 3. Bias pada OLS Estimator

Dari contoh model Keynesian sebelumnya, probability limit dari $\hat{\beta}\_1$ adalah:
$$\text{plim}(\hat{\beta}\_1) = \beta\_1 + \frac{1}{1-\beta\_1}\left(\frac{\sigma^2}{\sigma\_Y^2}\right)$$

Karena $0 < \beta\_1 < 1$ dan $\sigma^2, \sigma\_Y^2 > 0$, maka $\text{plim}(\hat{\beta}\_1) > \beta\_1$.

Simultaneous equation bias menunjukkan bahwa dalam model persamaan simultan:

1. Variabel di sisi kanan berkorelasi dengan error term
2. OLS menghasilkan estimator yang bias dan tidak konsisten
3. Magnitude bias tergantung pada $\beta\_1$, $\sigma^2$, $\sigma\_Y^2$, dan derajat korelasi antara Y dan u

Diperlukan metode estimasi alternatif seperti **Indirect Least Squares (ILS)** dan **Two-Stage Least Squares (2SLS)** yang dirancang khusus untuk menangani masalah simultaneity.

# Identification Problem

## 1. Notasi dan Definisi

### Bentuk Umum Model Simultan

Model persamaan simultan dengan M persamaan dan M variabel endogen:

$$Y\_{1t} = \beta\_{12}Y\_{2t} + \beta\_{13}Y\_{3t} + \cdots + \beta\_{1M}Y\_{Mt} + \gamma\_{11}X\_{1t} + \gamma\_{12}X\_{2t} + \cdots + \gamma\_{1K}X\_{Kt} + u\_{1t}$$

$$Y\_{2t} = \beta\_{21}Y\_{1t} + \beta\_{23}Y\_{3t} + \cdots + \beta\_{2M}Y\_{Mt} + \gamma\_{21}X\_{1t} + \gamma\_{22}X\_{2t} + \cdots + \gamma\_{2K}X\_{Kt} + u\_{2t}$$

$$\vdots$$

Di mana:

- $Y\_1, Y\_2, \ldots, Y\_M$ = M variabel endogen
- $X\_1, X\_2, \ldots, X\_K$ = K variabel predetermined
- $\beta$'s = koefisien variabel endogen (structural coefficients)
- $\gamma$'s = koefisien variabel predetermined
- $u$'s = error terms

### Reduced-Form Equations

Dari structural equations, kita dapat menurunkan **reduced-form equations** yang menyatakan setiap variabel endogen sebagai fungsi dari variabel predetermined saja.

Contoh: Model Keynesian $$C\_t = \beta\_0 + \beta\_1 Y\_t + u\_t$$ $$Y\_t = C\_t + I\_t$$

Reduced-form equations: $$Y\_t = \pi\_0 + \pi\_1 I\_t + w\_t$$ $$C\_t = \pi\_2 + \pi\_3 I\_t + w\_t$$

Di mana: $$\pi\_0 = \frac{\beta\_0}{1-\beta\_1}, \quad \pi\_1 = \frac{1}{1-\beta\_1}, \quad w\_t = \frac{u\_t}{1-\beta\_1}$$

Koefisien reduced-form ($\pi$'s) adalah kombinasi nonlinear dari structural coefficients ($\beta$'s).

### Impact Multipliers

Koefisien reduced-form seperti $\pi\_1$ disebut **impact multipliers** atau **short-run multipliers** karena mengukur dampak langsung perubahan satu unit variabel eksogen terhadap variabel endogen.

Contoh: Jika MPC = 0.8, maka $\pi\_1 = 1/(1-0.8) = 5$, artinya kenaikan investasi $1 akan meningkatkan pendapatan sebesar $5.

## 2. Identification Problem

### Definisi Masalah

**Identification problem** adalah: Dapatkah kita memperoleh nilai numerik unik dari structural coefficients dari estimated reduced-form coefficients?

- **Identified**: Parameter struktural dapat diperoleh secara unik
  - **Exactly identified**: Satu nilai unik untuk setiap parameter
  - **Overidentified**: Lebih dari satu nilai untuk beberapa parameter
- **Underidentified**: Parameter struktural tidak dapat diperoleh

### Underidentification

Model demand-supply sederhana: $$Q\_t^d = \alpha\_0 + \alpha\_1 P\_t + u\_{1t}$$ $$Q\_t^s = \beta\_0 + \beta\_1 P\_t + u\_{2t}$$

Reduced-form: $$P\_t = \pi\_0 + v\_t, \quad Q\_t = \pi\_1 + w\_t$$

Di mana: $$\pi\_0 = \frac{\beta\_0 - \alpha\_0}{\alpha\_1 - \beta\_1}, \quad \pi\_1 = \frac{\alpha\_1\beta\_0 - \alpha\_0\beta\_1}{\alpha\_1 - \beta\_1}$$

**Problem**: Ada 4 structural coefficients ($\alpha\_0, \alpha\_1, \beta\_0, \beta\_1$) tetapi hanya 2 reduced-form coefficients. Tidak mungkin mendapatkan estimasi unik untuk semua parameter struktural.

Hanya dengan data P dan Q, kita tidak dapat membedakan apakah kita mengestimasi demand function atau supply function. Setiap scatterpoint merepresentasikan intersection dari demand dan supply curves.

### Exact Identification

Tambahkan variabel income (I) ke demand function: $$Q\_t^d = \alpha\_0 + \alpha\_1 P\_t + \alpha\_2 I\_t + u\_{1t}$$ $$Q\_t^s = \beta\_0 + \beta\_1 P\_t + u\_{2t}$$

Reduced-form: $$P\_t = \pi\_0 + \pi\_1 I\_t + v\_t$$ $$Q\_t = \pi\_2 + \pi\_3 I\_t + w\_t$$

Sekarang supply function **identified** karena dapat diperoleh: $$\beta\_0 = \pi\_2 - \beta\_1 \pi\_0, \quad \beta\_1 = \frac{\pi\_3}{\pi\_1}$$

**Kunci**: Eksklusi variabel I dari supply function memungkinkan identifikasi. Demand function tetap underidentified.

### Overidentification

Tambahkan variabel wealth (R) ke demand dan lagged price ($P\_{t-1}$) ke supply: $$Q\_t^d = \alpha\_0 + \alpha\_1 P\_t + \alpha\_2 I\_t + \alpha\_3 R\_t + u\_{1t}$$ $$Q\_t^s = \beta\_0 + \beta\_1 P\_t + \beta\_2 P\_{t-1} + u\_{2t}$$

Reduced-form menghasilkan 8 coefficients untuk 7 structural parameters. Supply function sekarang **overidentified** karena $\beta\_1$ dapat diperoleh dengan dua cara: $$\beta\_1 = \frac{\pi\_6}{\pi\_2} \quad \text{atau} \quad \beta\_1 = \frac{\pi\_5}{\pi\_1}$$

Tidak ada jaminan kedua nilai ini identik.

## 3. Rules for Identification

### Notasi

- M = jumlah endogenous variables dalam model
- m = jumlah endogenous variables dalam suatu persamaan
- K = jumlah predetermined variables dalam model
- k = jumlah predetermined variables dalam suatu persamaan

### Order Condition (Necessary but Not Sufficient)

Untuk suatu persamaan identified: $$K - k \geq m - 1$$

Jumlah predetermined variables yang **excluded** dari persamaan harus ≥ jumlah endogenous variables yang **included** minus 1.

- Jika $K - k = m - 1$: **exactly identified**
- Jika $K - k > m - 1$: **overidentified**
- Jika $K - k < m - 1$: **underidentified**

**Interpretasi alternatif**: Persamaan harus mengeksklusi minimal M-1 variabel dari sistem untuk identified.

### Rank Condition (Necessary and Sufficient)

Dalam model M persamaan, suatu persamaan identified jika dan hanya jika minimal satu determinant nonzero berorder (M-1)×(M-1) dapat dibentuk dari koefisien variabel yang **excluded** dari persamaan tersebut tetapi **included** dalam persamaan lain.

**Prosedur penerapan:**

1. Tulis sistem dalam bentuk tabel (koefisien semua variabel)
2. Coret baris persamaan yang diperiksa
3. Coret kolom untuk variabel dengan koefisien nonzero dalam persamaan tersebut
4. Dari entries yang tersisa, bentuk matriks berorder (M-1)×(M-1)
5. Jika ada minimal satu determinant nonzero, persamaan identified

### Prinsip Umum Identifikasi

1. Jika $K - k > m - 1$ dan rank(A) = M-1: **overidentified**
2. Jika $K - k = m - 1$ dan rank(A) = M-1: **exactly identified**
3. Jika $K - k \geq m - 1$ dan rank(A) < M-1: **underidentified**
4. Jika $K - k < m - 1$: **underidentified** (rank pasti < M-1)

### Praktik

Order condition biasanya cukup untuk memastikan identifiability. Rank condition penting untuk dipahami tetapi jarang menyebabkan masalah dalam praktik jika order condition terpenuhi.

## 4. Test of Simultaneity

### Hausman Specification Test

Untuk menguji apakah simultaneity problem ada, gunakan Hausman test:

Contoh model: $$Q\_t^d = \alpha\_0 + \alpha\_1 P\_t + \alpha\_2 I\_t + \alpha\_3 R\_t + u\_{1t}$$ (demand) $$Q\_t^s = \beta\_0 + \beta\_1 P\_t + u\_{2t}$$ (supply)

**Prosedur:**

**Step 1**: Regress $P\_t$ pada semua predetermined variables (I dan R): $$P\_t = \pi\_0 + \pi\_1 I\_t + \pi\_2 R\_t + v\_t$$

Dapatkan residual $\hat{v}\_t$.

**Step 2**: Regress supply equation dengan menambahkan $\hat{v}\_t$: $$Q\_t = \beta\_0 + \beta\_1 P\_t + \beta\_1 \hat{v}_t + u_{2t}$$

**Test**: Lakukan t-test pada koefisien $\hat{v}\_t$.

- Jika signifikan: simultaneity problem exists
- Jika tidak signifikan: no simultaneity problem

**Intuisi**: Jika $P\_t$ endogen, maka $P\_t$ berkorelasi dengan $u\_{2t}$. Korelasi ini akan tertangkap oleh $\hat{v}\_t$ (residual dari reduced-form regression). Jika koefisien $\hat{v}\_t$ signifikan, berarti $P\_t$ memang endogen dan ada simultaneity problem.

### Test for Exogeneity

Hausman test juga dapat digunakan untuk menguji apakah suatu variabel benar-benar eksogen atau endogen.

Untuk persamaan: $$Y\_{1i} = \beta\_0 + \beta\_2 Y\_{2i} + \beta\_3 Y\_{3i} + \alpha\_1 X\_{1i} + u\_{1i}$$

**Prosedur:**

1. Dapatkan reduced-form untuk $Y\_2$ dan $Y\_3$, dapatkan $\hat{Y}_{2i}$ dan $\hat{Y}_{3i}$
2. Estimate: $$Y\_{1i} = \beta\_0 + \beta\_2 Y\_{2i} + \beta\_3 Y\_{3i} + \alpha\_1 X\_{1i} + \lambda\_2 \hat{Y}_{2i} + \lambda\_3 \hat{Y}_{3i} + u\_{1i}$$
3. F-test untuk $H\_0: \lambda\_2 = \lambda\_3 = 0$
   - Jika reject: $Y\_2$ dan $Y\_3$ endogen
   - Jika tidak reject: dapat diperlakukan sebagai eksogen

### Kesimpulan

Identification problem adalah langkah logis sebelum estimation. Tanpa identifikasi yang tepat, parameter struktural tidak dapat diestimasikan secara unik. Order dan rank conditions memberikan tools sistematis untuk mengecek identifiability, sementara Hausman test membantu memverifikasi apakah simultaneity problem memang ada dalam data.
